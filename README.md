# DeepRayTracing
RayTracing for optical design using deep learning


Bonjour

Ce programme est un prototype de tracé de rayons utilisant de l'apprentissage profond.
Cette version a été testée seulement avec un système composée d'une lentille simple convexe
Celui-ci utilise une version modifiée de la librairie optiland où les fonctions d'affichage 3D de la librairie ont été enlevées, pour l'utiliser, simplement extraire le dossier "optiland.zip" dans un dossier "optiland".
Il est possible d'utiliser ce programme en installant optiland de façon classique seulement dans la version 3.10 de Python

Les autres instalations prérequises sont affichées dans tracé_de_rayons.ipynb
